# E-Commerce Sales & Customer Intelligence Dashboard

An end-to-end Data Analytics project developed using **SQL Server, Excel, Python, and Power BI** to analyze the Olist Brazilian E-Commerce dataset and generate business insights for executive decision-making.

## Project Overview

This project analyzes e-commerce sales data to understand customer behavior, revenue trends, payment preferences, seller performance, and delivery efficiency.

The project follows a complete analytics workflow:

- Data Analysis using SQL
- Data Validation using Excel
- Exploratory Data Analysis (EDA) using Python
- Interactive Dashboard Development using Power BI
- Business Insights for decision-making

## Business Objectives

This project answers important business questions such as:

- Which product categories generate the highest revenue?
- Which payment methods are preferred by customers?
- Which states have the highest customer base?
- Which sellers contribute the most revenue?
- What is the average delivery time?
- How satisfied are customers based on review scores?
- What are the order status distributions?

# Key Business Insights

- Credit Card is the most preferred payment method.
- A few product categories contribute a significant share of total revenue.
- Most customers are concentrated in São Paulo and other major states.
- Most orders are delivered successfully.
- Customer ratings remain consistently high, indicating overall satisfaction.
- Delivery times vary across states, highlighting opportunities to improve logistics.
- Top-performing sellers contribute a substantial portion of total revenue.
